Это переписанный на Rust [Rectangle](https://github.com/rxhanson/Rectangle), популярный оконный менеджер для macOS.
Умеет всё, что умеет оригинал, и немного больше: например, сам выстраивает все окна Терминала ровными столбиками.

- 🖱 **Только мышь.** Перетащил окно к краю, и оно встало на половину экрана. Никаких сочетаний клавиш запоминать не надо.
- 🇷🇺 **Полностью на русском.**
- 🪶 **Лёгкий.** Приложение весит 3 МБ и работает только из строки меню, в доке его нет.
- 💻 **Любой Mac** на Apple Silicon (M1–M4) или Intel, macOS 11 и новее.

## 📦 Установка

### Вариант 1: одной командой (проще всего)

Открой **Терминал** (⌘ + пробел → набери «Терминал» → Enter), вставь строку и нажми Enter:

```sh
curl -fsSL https://raw.githubusercontent.com/Lutamona/Rectangle2Rust/main/install.sh | bash
```

Скрипт скачает приложение, положит его в «Программы» и запустит. Той же командой потом обновляешься.

### Вариант 2: вручную

1. [Скачай архив](https://github.com/Lutamona/Rectangle2Rust/releases/latest/download/Rectangle2Rust.zip) и открой его: появится «Rectangle 2 (Rust)».
2. Перетащи приложение в папку **«Программы»**.
3. Запусти. macOS скажет, что не может проверить разработчика: приложение бесплатное и не куплено у Apple, так пишет про всё подобное. Нажми **«Готово»**, открой **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз и нажми **«Всё равно открыть»**.

### Последний шаг: дать доступ

При первом запуске приложение попросит **доступ к управлению окнами**. Без этого доступа двигать окна оно не сможет.

**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ →** включи переключатель у «Rectangle 2 (Rust)».

Если переключатель уже включён, а окна не двигаются, выключи его и включи обратно.

## 🖱 Как пользоваться

| Что сделать | Что будет |
|---|---|
| Тащишь окно за заголовок **к левому или правому краю** | окно встаёт на половину экрана |
| Тащишь **в угол** | окно встаёт на четверть |
| Тащишь **к верхнему краю** | окно разворачивается на весь экран |
| Тащишь **к нижнему краю** | окно встаёт на треть; веди вдоль края, чтобы выбрать какую |
| **Двойной клик** по заголовку окна | развернуть или вернуть (настраивается) |
| Кликаешь по **иконке в строке меню** | меню со всеми раскладками: трети, четверти, шестые, столбики 5–8, центр, соседний экран… |

Если оттащить окно от края, оно вернёт свой прежний размер.

### ⭐ Окна столбиками

Лучшая фишка для тех, у кого открыто десять терминалов:

- **«Окна приложения столбиками»** в меню расставляет все окна текущего приложения ровными столбиками во всю высоту экрана.
- **«Держать окна «Терминал» столбиками»** (галочка) делает это автоматически: открыл новое окно, и все подвинулись, закрыл одно, и остальные растянулись.

### Настройки

Меню → **«Настройки…»**. Там зазоры между окнами, запуск при входе, поведение при перетаскивании, приложения-исключения, импорт и экспорт настроек (формат совместим с оригинальным Rectangle).

## ❓ Частые вопросы

**Окна не двигаются.** Проверь доступ (см. [Последний шаг](#последний-шаг-дать-доступ)). После обновления приложения доступ иногда приходится выключить и включить заново.

**Конфликтует со встроенной раскладкой macOS 15.** Приложение само предупредит об этом и предложит выключить системную раскладку, чтобы они не мешали друг другу.

**Как удалить?** Меню → «Выйти», потом перетащи приложение из «Программ» в корзину.

**Это безопасно?** Код открыт, весь он лежит здесь. Приложение не ходит в интернет и ничего никуда не отправляет.

## 🛠 Для программистов

Порт Swift-приложения на Rust через [`objc2`](https://github.com/madsmtm/objc2): AppKit, Accessibility API, CGEvent tap. Геометрия раскладок сверялась с настоящим Swift-кодом Rectangle на сотнях тысяч случаев, и числа совпадают до бита. В проекте 435 тестов.

```sh
git clone https://github.com/Lutamona/Rectangle2Rust && cd Rectangle2Rust
cargo test --release
./build.sh              # → dist/Rectangle2Rust.app
./build.sh --install    # то же и установка в /Applications
./build.sh --universal  # Apple Silicon + Intel (rustup target add x86_64-apple-darwin)
./build.sh --dev        # отдельная тестовая копия со своими настройками
```

Нужен Rust (stable) и Xcode Command Line Tools. Если в связке ключей есть сертификат Apple Development, `build.sh` подпишет им, и доступ не будет слетать после пересборки. Иначе будет ad-hoc подпись.

<details>
<summary>URL-схема (для Raycast, Alfred, скриптов)</summary>

```sh
open "rectangle2rust://execute-action?name=left-half"
open "rectangle2rust://execute-action?name=column-five1"
open "rectangle2rust://execute-task?name=ignore-app"
open "rectangle2rust://execute-task?name=unignore-app&app-bundle-id=com.apple.Terminal"
```

Имена действий как у Rectangle, в kebab-case (`leftHalf` → `left-half`). Горячие клавиши можно назначить через эти ссылки в любом лаунчере.
</details>

<details>
<summary>Чем отличается от оригинального Rectangle</summary>

- Нет горячих клавиш: управление только мышью и меню (или через URL-схему).
- Интерфейс только на русском.
- Действия, у которых в оригинале был только шорткат, собраны в подменю «Другое».
- Добавлены «Окна приложения столбиками» и столбики 5–8.
- Нет автообновления: обновляешься командой установки.
- Запуск при входе работает с macOS 13.
- Настройки хранятся в `UserDefaults` домена `local.rectangle2rust` под теми же ключами, что у оригинала. Все ключи описаны в [docs/settings.md](docs/settings.md).
</details>
